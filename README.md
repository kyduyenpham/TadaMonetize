# 🚀 TADA v2: Transforming a Content Platform into a Fintech Monetization Ecosystem

**Role:** Business Analyst → Product Owner  
**Duration:** Jul 2024 – Apr 2025  
**Industry:** Webtoon/Novel Platform, Fintech Monetization  
**Country:** Vietnam ↔ Indonesia (Investor Collaboration)

---

## 🧭 Project Overview

TADA v2 is a **9-month transformation project** evolving a Vietnamese content platform from a free-read library into a **fintech-powered monetization ecosystem**.

The upgraded system enables creators and users to earn through **7 revenue streams**, supported by a **bilingual earning dashboard (EN/VN)** for transparency.

### **My Responsibilities**
- Led requirement elicitation, backlog management, and investor communication  
- Designed monetization flows, wallet logic, and revenue-sharing engine  
- Created BPMN diagrams, revenue rule matrix, and system data flow  
- Managed cross-functional alignment (VN team ↔ Indonesia investors)  
- Delivered **UAT-approved** system with automated revenue engine

**Tech Stack & Tools:** Jira, Confluence, Figma, Miro, Zoom, WebSocket, Redis, Momo API, ZaloPay API, Banking API

---

## ❗ Problem Statement

Before TADA v2, the platform suffered from:

- **No monetization** → no income for creators  
- **Manual Excel-based reporting** → no transparency for investors  
- **Low engagement** → lack of incentives or referral system  
- **No wallet architecture** → transactions not traceable
